# Helper Scripts (root)

Scripts here are for **legacy or one-off** use (e.g. detect_changes, parse_databases_env, migrate_to_sections).

**Compose generation** and port allocation now live under **`scripts/helpers/`** and are used by `scripts/db_manager.sh`, `scripts/redis_manager.sh`, and `scripts/livekit_manager.sh`. Run management via `./container_manager.sh` or `./db_manager.sh` from the project root.
